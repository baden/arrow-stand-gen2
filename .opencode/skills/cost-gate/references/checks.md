# Чек-лист вартісного gate'у

Короткий список. Пройди перед тим, як запропонувати зміну.

## Перед зміною

- [ ] Яку вимогу обслуговує зміна? (FR-xx / NFR-xx з `docs/00-requirements.md`)
- [ ] Чи немає вже наявної деталі, яка підходить? (унікальні позиції = setup-fee)
- [ ] Пакет: 0402/0603/0805 → SOT-23 → SOP/TSSOP → SOIC. LGA/QFN/BGA — ні.
- [ ] Деталь реально доступна (LCSC, сток ≥ 3× партії)?
- [ ] Чи є в BOM деталь із тим самим номіналом (тоді позиція не з’явиться)?

## Після зміни

- [ ] Δ$ вказано явно: `+$X.XX/шт`
- [ ] Новий підсумок вказано: `$Y.YY`
- [ ] Підсумок ≤ $3.75 (мета). Якщо > $4.50 — стоп, потрібен ADR.
- [ ] `hardware/bom/bom-draft.csv` оновлено (включно з `rationale`)
- [ ] `docs/cost/budget.md` перераховано
- [ ] Ціни знято зі сходинки LCSC (`tools/lcsc_prices.py`), не базова ціна за 1 шт.
- [ ] Кількість унікальних позицій не зросла (або зріст обґрунтований)
- [ ] Модель складання (ADR-0006) не порушена: нова деталь паябельна
- [ ] Немає деталей «про запас»

## Дрібні правила

| Правило | Деталі |
|---|---|
| Номінал | Не додавай новий номінал, якщо є близький, що вже в BOM |
| Кількість | Одна позиція — один номінал. 10 k + 10 k = одна позиція |
| Живлення | Один LDO на всі 3.3 В навантаження, якщо струм дозволяє |
| Індикація | LED статусу = опційно; за замовчуванням не ставити |
| Тест | Точки WCH ISP (PDI/SCLK) — обов'язкові, це не «запас» |
| Кварц | Тільки якщо реально потрібний; внутрішній RC дешевше |
