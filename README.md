# arrow-stand-gen2 — бездрововий датчик влучання в мішень

Пристрій, що кріпиться на мішень, фіксує удар (акселерометр), і бездрово передає
факт влучання на базову станцію (приймач) за LoRa.

**Мета проєкту — мінімально можлива собівартість.** Пристрій розхідний: він
отримує удари і, можливо, знищується під час стрільби. Тому критерії відбору
компонентів — не «найкраще», а «дешевше, при цьому працює».

## Ліцензії та походження

Компоненти — з LCSC/JLCPCB. Перед серійною парттією перевірити локальні
регуляторні вимоги до діапазону й потужності передавача (ETSI EN 300 220 /
FCC Part 15) та правила літій на зони ураження.
