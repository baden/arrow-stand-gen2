# 00 — Вимоги до пристрою (DRD)

> Статус: draft v0.1 · Оновлено: 2026-11-18

Це документ вимог. Якщо реалізація суперечить цьому файлу — або оновлюємо
цей файл, або фіксуємо відхилення в ADR.

## 1. Призначення

Пристрій фіксує факт механічного удару (попадання стріли) в мішень і
бездрово передає цю подію базовій станції протягом обмеженого часу.

## 6. Вимоги до живлення

- LiPo 1S 3.7 В, ємність 200–500 мАг.
- Заряд: TP4056 + захист від розрядження (вбудований MOSFET у TP4056).
- Розрядний канал: окремий MOSFET або вимкнення живлення (для максимальної
  економії — див. відкрите питання Q-04).
- LDO 3.3 В з EN-входом (ME6211) або без EN (XC6206, дешевше на $0.04).

## 7. Вимоги до виявлення удару

- Діапазон вимірювання ≥ ±16 g (удар стріли — десятки g).
- Частота дискретизації ≥ 1 kHz (удар — одинична подія).
- Поріг спрацювання — налаштовуваний, за замовчуванням 4 g.
- Реалізувати фільтр і debounce, щоб один удар давав один пакет.

## 8. Вимоги до протоколу

Формат пакета (пропозиція, ADR):

```
struct evt_packet {          // 17 байт, версія протоколу 0x02
  uint8_t  magic;      // 0xA5
  uint8_t  ver;        // 0x02
  uint16_t device_id;  // унікальний ID пристрою
  uint32_t seq;        // лічильник подій
  uint16_t peak_mg;    // піковий модуль прискорення, мг
  uint16_t impulse;    // інтеграл |a| за вікно події, мг·с
  uint8_t  klass;      // результат класифікації (ADR-0008):
                       //   0 unknown, 1 стріла, 2 легкий дотик,
                       //   3 похитування мішені, 4 шум
  uint8_t  flags;      // біт 0: сигнал насичено (|a| = 16 g)
  uint16_t batt_mv;    // напруга батареї, мВ
  uint8_t  crc;        // CRC8 (поліном 0x07, init 0xFF) по байтах 0..15
} __packed;            // 17 байт
```

Класифікація виконується **на пристрої** (ADR-0008); хаб отримує готовий
результат.

LoRa: **SF11, BW 125 кГц**, CR 4/5, захист CRC, преамбула 12 символів —
власний P2P-протокол, без LoRaWAN (ADR-0007). SF11 вибрано для >1 км:
+6 дБ чутливості = ×2 дальності; пакет 16 Б при SF11 передається ~1 с, що
для події «удар» прийнятно.

## 9. Питання до замовника (відкриті)

| ID | Питання | Впливає на |
|---|---|---|
| Q-01 | Яка реальна дальність потрібна? (100 м / 500 м / 1 км+) | Вибір LoRa-параметрів, SX1262 vs дешевша альтернатива |
| Q-02 | Який діапазон: 433 / 868 / 915 МГц? | SX1262 покриває всі, але антена й регламент |
| Q-03 | Скільки пристроїв і яка партія? (100? 1000?) | Ціна LCSC, setup fee, вибір виробника |
| Q-04 | Чи потрібний окремий вимикач живлення? | MOSFET + кнопка (~$0.03) vs без |
| Q-05 | Ручна пайка чи SMT на замовлення? | Вибір пакетів (LGA vs SOP) |
| Q-06 | Частота повторних влучань у мішень — реальна? | Debounce, живлення, міцність |
