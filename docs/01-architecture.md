## 1. Система

Система складається з двох частин:

│                             │             │  БАЗОВА СТАНЦІЯ (Hub)   │
│  [LiPo 3.7V]                │             │  LoRa приймач + ESP32/   │
│      │                      │             │  Raspberry Pi + лог      │

## 2. Блоки пристрою

### 2.1 Живлення
- **LiPo 1S** 3.7 В, 200–500 мАг.
- **TP4056-42-ESOP8** — заряд 1 А, termination 4.2 В, вбудований MOSFET, $0.148 @100 шт.
- **ME6211C33M5G-N** — LDO 3.3 В / 500 мА / SOT-23-5, $0.051 @100 шт, EN-вхід.
  Альтернатива `XC6206P332MR` — ~$0.015, SOT-23-3, без EN.
- Опційно: кнопка живлення + MOSFET (Q-04).

Струм: SX1262 TX 22 dBm → ~120 мА пік; MCU ~10 мА; акселерометр 0.5 мА.
LDO повинен тримати пік 120 мА без просадки — 500 мА із запасом.

### 2.2 Радіотрансивер
- **SX1262IMLTRT** (C191341), QFN-24-EP 4×4 мм, $1.9061 @100 шт.
- Діапазон 150–960 МГц, TX +22 dBm, RX 4.6 мА, чутливість −148 dBm.
- SPI-інтерфейс, вбудований DC-DC і LDO всередині.
- **32 МГц** кварц (3225-4P, 12 pF) + 2 конденсатори 12 pF (CL = (C1·C2)/(C1+C2)+Cstray).
- Живлення: 100 нФ на VDD (≤ 5 мм), 10 мкФ на VDDA.

### 2.3 Мікроконтролер
- **CH32V203F8U6** (C7570477), QFN-20 3×3, 64 KB Flash, 20 KB SRAM,
  RISC-V QingKe V4B, 144 МГц, VDD 2.4–3.6 В, $0.3852 @100 шт.
- Тактовий: внутрішній RC 8 МГц + PLL (без зовнішнього кварцу).
- Ядро RV32IMAC: одноциклове множення, апаратне ділення (без FPU).
- Програмування: 2-провідний WCH ISP (PDI/SCLK) — 2 тестові площадки в PCB.

### 2.4 Акселерометр
- Кандидат: **SC7A20HTR** (C19274408) — LGA-12 2×2 мм, ±16 g, SPI/I2C, $0.1995 @100 шт.
- Альтернативи: LIS2DH12TR ($0.89, ST), LIS3DHTR ($1.81, ST).
- Вихід: 12-біт, ODR до 3.2 kHz, вбудований threshold-детектор і FIFO.

### 2.5 Антена
Відкрите питання (ADR-0004). Варіанти:
- PCB-антенна (trace, ~$0) — дешево, потребує ground-plane-конфігурації, менша дальність.
- SMA-роз'єм на PCB (~0.15) + зовнішня антена — гнучко, більша за розмір.
- U.FL/IPEX (~0.10) + зовнішня антена — компактно.

## 3. Протокол зв'язку

Пакет події — 17 байтів (див. `docs/00-requirements.md` §8). LoRa: **433 МГц, SF11, BW 125 кГц** (ADR-0005, ADR-0007).

Передача: LoRa з preamble 12, SF9, BW125, CR4/5. Повторна відправка — 3 рази
з інтервалом 250 мс (для надійності в місті).

## 4. Потік живлення / режими

```
        ┌────────────┐   удар    ┌───────────┐
        │  DEEP SLEEP │ ─────────►│  ACTIVE   │
        │  ~2 мкА     │            │ читає acc │
        └────────────┘            └─────┬─────┘
                                       │ подія
                                       ▼
                                ┌─────────────┐   TX    ┌────────┐
                                │ WAKE + SEND │ ───────► │  LoRa  │
                                └─────────────┘          └────────┘
                                       │ timeout
                                       ▼
                                ┌─────────────┐
                                │  DEEP SLEEP │
                                └─────────────┘
```

## 5. Розподіл витрат (орієнтовно)

| Режим | Струм | Частота | Середнє |
|---|---|---|---|
| Deep sleep | ~2 мкА | весь час | 2 мкА |
| Wait-for-interrupt (acc ODR 12.5 Hz) | ~30 мкА | постійно | 30 мкА |
| Active (вимірювання + TX) | ~130 мА | ~1 подія / хвилину | ~2 мкА avg |

LiPo 200 мАг → орієнтовно 30+ днів у режимі очікування.
