# ADR-0001 — Радіотрансивер: SX1262IMLTRT

- **Статус:** accepted (потребує підтвердження бюджетом — див. Q-01/Q-03)
- **Дата:** 2026-11-18
- **Пов'язані:** FR-02, NFR-01, NFR-02, ADR-0005

## Контекст

Потрібен дальнобійний ( hundreds…kilometers ) низькоспоживний бездрововий канал
для передачі одного короткого пакета події. Дальність — орієнтовно 300 м+
(місцевість, мішень у тирі), бажано 1 км.

Обмеження — вартість. Пристрій розхідний, тому радіо не може коштувати
більше за решту пристрою разом.

## Наслідки

**Позитивні:** один і той самий чип покриває 433/868/915 МГц; TX +22 dBm;
низьке споживання в RX (важливо для батареї); широки вибір SF/BW.

**Негативні / ризики:**
- **Радіо — 62 % собівартості пристрою** ($1.91 з $3.06). Бюджетний ризик №1.
- QFN-24 4×4 — не паяється паяльною станцією; потрібен трафарет/печ
  або SMT. Порівняно з LGA-12 акселерометра — це ще складніше.
- Потрібен зовнішній кварц 32 МГц (ще одна деталь, $0.10 @100) і 2 конденсатори.
- Extended library → setup-fee ~$3 за позицію при SMT-замовленні.

### Параметри LoRa (ADR-0007)

| Параметр | Значення | Обґрунтування |
|---|---|---|
| SF | **11** (запас — SF12) | Дистанція > 1 км: +6…9 дБ чутливості = ×2…3 дальності |
| BW | 125 кГц | Максимальна чутливість |
| CR | 4/5 | Стандарт |
| Преамбула | 12 символів | Стандарт |
| CRC | увімкнено | Стандарт LoRa |
| Протокол | **власний P2P** (не LoRaWAN) | хаб свій; Semtech LoRa Basics Modem (40 KB / 6 KB) не потрібен |
| Повтори | 3 × 250 мс | Надійність у місті |

Пакет 13 байт при SF11/BW125 → повільно (~1 с), що для події «удар»
абсолютно прийнятно і вигідно: повільніший = далекіший.

**Що це змушує робити далі:**
- R-01: рахувати tier-ціни на 100/500/1000 шт — **виконано 2026-11-18**,
  див. `docs/cost/cost-model.md` §2 та `hardware/bom/lcsc-prices.csv`.
- Q-03: вирішити модель складання (ADR-0006) — вона визначає, чи є setup-fee
  взагалі в бюджеті.
- ADR-0005: зафіксувати частоту (впливає на антену).
- ADR-0004: для >1 км зовнішня антенна **обов'язкова** — PCB-антена не
  дає потрібного бюджету посилення.
- R-13: виміряти дальність з реальними антенами.

## Перевірка

- Дальність: вимірювання в реальних умовах (R-06), мінімум 300 м.
- Струм TX: вимірювання у режимі 22 dBm, очікуємо ≤ 130 мА.
- Ціна: знімати з сходинки LCSC перед кожною партією (`tools/lcsc_prices.py`) —
  базова ціна за 1 шт. не є показником.
