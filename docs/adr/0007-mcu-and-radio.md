# ADR-0007 — Вибір MCU та радіо: CH32V203F8U6 + SX1262

- **Статус:** accepted
- **Дата:** 2026-11-18
- **Пов'язані:** ADR-0001, ADR-0002, ADR-0003, ADR-0004, ADR-0005, NFR-01, NFR-02,
  Q-01 (закритий), Q-02 (відкрите), `docs/research/mcu-radio-tradeoff.md`

## Контекст

Три сумніви замовника щодо CH32V003F4P6: чи вистачить MCU, скільки місця
займає LoRa-стек, і чи потрібен LoRa взагалі. Додатково: монтаж планується
SMT, тож обмеження на пакети зняте.

**Відповіді замовника (2026-11-18):**

| Питання | Відповідь | Наслідок |
|---|---|---|
| Q-01 дистанція | **більше 1 км** | LoRa **обов'язковий**; BLE (CH572/CH583/CH32V208) відпадає |
| Протокол | **власний, хаб свій** | LoRaWAN не потрібен → Semtech LoRa Basics Modem (40 KB / 6 KB) **не потрібен** |

## Рішення

**MCU: WCH CH32V203F8U6** (LCSC C7570477, QFN-20 3×3, $0.3852 @100 шт) —
замість CH32V003F4P6.

**Радіо: SX1262IMLTRT** без змін (ADR-0001).

**LoRa-стек: власний мінімальний драйвер SX1262** (регістрові команди,
LoRa point-to-point), **не** Semtech LoRa Basics Modem.

**LoRa-параметри: SF11–SF12, BW 125 кГц** — 13-байтний пакет дозволяє
повільну передачу заради запасу по чутливості (+6…9 дБ = ×2…3 дальності).

**Алгоритм виявлення удару — на пристрої** (детект + ознаки), **класифікація
(AI) — на хабі**.

## Обґрунтування

### Чому MCU міняється

| | CH32V003F4P6 | CH32V203F8U6 |
|---|---|---|
| Flash | 16 KB | **64 KB** |
| SRAM | 2 KB | **20 KB** |
| Частота | 48 МГц | **144 МГц** |
| Ядро | RV32EC — **без апаратного множення** | V4B (IMAC) — одноциклове множення, апаратне ділення |
| SPI / I2C / USB | 1 / 1 / — | 1 / 1 / USB FS |
| Ціна @100 | $0.2396 | $0.3852 (**+$0.1456**) |

Причина не в алгоритмі (він уміщається в будь-який), а в тому, що:

1. **Радіо-стек тепер наш власний** — Semtech LoRa Basics Modem (40 KB / 6 KB)
   відпадає, тож драйвер пишемо ми. Своїй код важко вписати в 16 KB з
   2 KB RAM, коли вже є запас за рахунок дешевшого чіпа на $0.15.
2. **Плани на DSP/AI** — 20 KB SRAM проти 2 KB. Різниця якісна: аналіз
   спектра, буфери, модель.
3. **144 МГц і апаратне множення/ділення** — рахувати RMS/FFT/нормалізацію
   на 48 МГц без множення — марно.
4. **Розширюваність** — 64 KB Flash дає місце на майбутні протоколи,
   діагностику, калібрування.

$0.15 за пристрій = $15 на 100 шт. або $150 на 1000 шт. На тлі $1.91
радіо — це 7 % бюджету пристрою.

### Чому не CH572D

Дистанція > 1 км → BLE не підходить (50–200 м у прямій видимості).

### Чому не залишити CH32V003

R-12 (прототип міні-драйвера SX1262) має показати, що драйвер + застосунок
+ алгоритм уміщаються в 16 KB / 2 KB. Якщо R-12 це доведе — CH32V003 можна
повернути й зекономити $0.15/шт. **Це не блокер, а запасний варіант.**

## Альтернативи

| Варіант | Ціна/шт | Чому відхилено |
|---|---|---|
| CH32V003F4P6 + SX1262 | $3.06 | немає запасу на власний LoRa-драйвер + DSP; 16 KB / 2 KB |
| CH32V203G6U6 | $3.28 | 32 KB Flash — менше, ніж у F8x6, при вищій ціні |
| CH32V203C8T6 (LQFP-48) | $3.48 | той самий кристал, але більший корпус і дорожче |
| CH32V203F6P6 | $3.11 | 32 KB Flash / 10 KB SRAM — теж тісно для драйвера + алгоритму |
| CH572D / CH583M / CH32V208 | $1.12–1.77 | LoRa не забезпечує (>1 км) |
| SX1278IMLTRT | — | $2.9 @100, але 137–525 МГц (не 868/915) і 10.8 мА RX |

## Наслідки

**Позитивні:**
- Є місце для власного LoRa-драйвера і для алгоритму/DSP.
- Запас по пам'яті: можна додати LoRaWAN пізніше, якщо знадобиться.
- 144 МГц — швидкіший DSP, нижча затримка реакції.
- QFN-20 3×3 — компактно, SMT без проблем.

**Негативні / ризики:**
- +$0.15/шт.
- Інший toolchain/SDK (MounRiver), ніж для CH32V003.
- Власний LoRa-драйвер — це робота і відповідальність (хоча протокол
  точний-to-point, без LoRaWAN).
- Немає FPU (V4B = IMAC). Для float-розрахунків — fixed-point; наш стек
  протоколу — fixed-point і так.

**Що це змушує робити далі:**
- ADR-0002 → прийнято CH32V203F8U6.
- ADR-0001 → LoRa SF11/SF12, власний P2P-протокол.
- ADR-0004 → **зовнішня антенна обов'язкова** (SMA), PCB-антена не дає 1 км.
- ADR-0005 → закрити частоту (Q-02): 433 / 868 / 915.
- R-12: прототип драйвера SX1262 і вимірювання його фактичного розміру.
- R-13: дальність LoRa з зовнішньою антеною.
- R-05: струм (144 МГц + DMA потребують перевірки режиму сну).

## Перевірка

- Прошивка: Flash ≤ 60 % (≤ 38 KB), RAM ≤ 50 % (≤ 10 KB).
- R-12: драйвер SX1262 вміщається разом із застосунком і алгоритмом.
- R-13: ≥ 1 км на реальній дистанції з зовнішніми антенами.
- R-05: струм у sleep не погіршився.
- Вартість пристрою ≤ $3.50.
