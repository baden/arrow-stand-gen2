# Модель вартості

> Ціни: LCSC, цінова содинка (ladder), знято 2026-11-18.
> Інструмент: `tools/lcsc_prices.py` → `hardware/bom/lcsc-prices.csv`.

## 1. Склад моделі

```
Вартість пристрою = PCB + Σ(деталі за обсягом) + setup_fee(позиції) + операційні(збірка) + батарея + корпус
```

## 2. Розриви сходинки — вони різні для кожної деталі

Це головна підводність: **не можна брати «ціну за 100» у всіх деталей однаково**.
У LCSC кожна позиція має власні точки розриву.

| Деталь | LCSC | Розриви | @1 | @100 | @1000 |
|---|---|---|---|---|---|
| SX1262IMLTRT | C191341 | 1/10/30/100/500/1000 | $3.2406 | $1.9061 | $1.7178 |
| CH32V003F4P6 | C5187096 | 5/50/150/500/2500/4000 | $0.3079 | $0.2396 | $0.1478 |
| CH32V003A4M6 | C5346357 | 5/50/150/500/2500/5000 | $0.2841 | $0.2264 | $0.1709 |
| CH32V003J4M6 | C5346354 | 5/50/150/500/2500/4000 | $0.2702 | $0.2142 | $0.1603 |
| SC7A20HTR | C19274408 | 1/10/30/100/500/1000 | $0.2969 | $0.1995 | $0.1766 |
| LIS2DH12TR | C110926 | 1/10/30/100/500/1000 | $0.8959 | $0.5412 | $0.4950 |
| ME6211C33M5G-N | C82942 | 10/100/300/3000/6000/9000 | $0.0630 | $0.0511 | $0.0399 |
| TP4056-42-ESOP8 | C16581 | 5/50/150/500/2500/4000 | $0.1869 | $0.1480 | $0.0892 |
| E3SB32E00000KE | C1021665 | 5/50/150/500 | $0.1275 | $0.1017 | $0.0792 |

**Правило:** для деталі з розривом 50 ціна на 100 шт. — це ціна сходинки «50».
Для деталі з розривом 100 — ціна сходинки «100». Тому в БД Copperpour
(`search_jlcpcb_parts`) ціна завжди за 1 штуку — і для SX1262, і для
CH32V003 вона вища за реальну в 1.4–1.7 рази.

## 3. Setup-fee за унікальну позицію

| Бібліотека JLCPCB | Setup-fee |
|---|---|
| Basic | $0 |
| Preferred | $0 |
| Extended | **~$3 за позицію** |

| Позиція | Бібліотека | Setup-fee |
|---|---|---|
| SX1262IMLTRT | Extended | $3 |
| CH32V003F4P6 | Extended | $3 |
| SC7A20HTR | Extended | $3 |
| ME6211C33M5G-N | Extended | $3 |
| E3SB32E00000KE (кварц) | Extended | $3 |
| TP4056-42-ESOP8 | Preferred | $0 |
| **Разом** | | **~$15 одноразово** |

При 100 шт це $0.15/шт (5 % пристрою), при 1000 шт — $0.015/шт.

## 4. Порівняння моделей складання (на 100 шт)

| Стаття | A: PCB + ручна пайка | B: SMT від JLCPCB | C: локальний SMT |
|---|---|---|---|
| PCB | $0.35 | $0.35 | $0.35–0.60 |
| Деталі | $2.71 | $2.71 | $2.71 |
| Setup-fee | $0 | ~$15/100 = $0.15 | $0 або ~$5–10 |
| Операційні | праця ~1 год/шт | ~$1.50–3.00/шт | ~$0.50–1.50/шт |
| **Разом за шт** | **~$3.06 + 1 год праці** | **~$4.71–6.21** | **~$3.71–4.91** |
| Складність пайки | LGA/QFN проблемні | немає | немає |

## 7. Як оновлювати

```bash
python3 tools/lcsc_prices.py --from-bom hardware/bom/bom-draft.csv --qty 100 \
    --out hardware/bom/lcsc-prices.csv --update-bom
python3 tools/cost_model.py --bom hardware/bom/bom-draft.csv --check
```

Перший — знімає сходинку з LCSC і оновлює `unit_price_usd` у BOM
(додає колонку `price_basis`). Другий — перераховує бюджет і перевіряє
ціль $3.50.
