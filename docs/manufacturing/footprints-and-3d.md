# Перевірка футпрінта SC7A20HTR і 3D-моделі

> Дата: 2026-11-18 · Джерела: SC7A20H DS0 v0.7 (31 с.), EasyEDA/JLCEDA API,
> JLCPCB Assembly Capabilities + Opening Process Standard.

## 1. Розведення виводів — збігається 1:1

Даташит SC7A20H (стор. 6, «管脚描述»):

| Pin | Символ | Наш символ | ✓ |
|---|---|---|---|
| 1 | SDO | SDO (MISO) | ✓ |
| 2 | SDx | SDx (MOSI) | ✓ |
| 3 | VDDIO | VDDIO → VCC_3V3 | ✓ |
| 4 | NC | NC | ✓ |
| 5 | INT1 | INT1 → INT_ACC | ✓ |
| 6 | INT2 | INT2 → NC | ✓ |
| 7 | VDD | VDD → VCC_3V3 | ✓ |
| 8 | GNDIO | GNDIO → GND | ✓ |
| 9 | GND | GND → GND | ✓ |
| 10 | CS | CS → CS_ACC | ✓ |
| 11 | NC | NC | ✓ |
| 12 | SCx | SCx (SCK) | ✓ |

**Режим SPI:** даташит описує 4-дротовий і 3-дротовий SPI. Наша схема —
4-дротовий: SDO=SDO, SDx=SDI, SCx=SCK, CS=0 → SPI ✓. У 3-дротовому
SDO не використовується — ми його не застосовуємо.

## 2. Розміри корпусу й рекомендований land pattern (стор. 29)

LGA-12-2×2×1.0, TOP VIEW з маркером PIN 1 і LASER MARK.

| Символ | MIN | NOM | MAX | Що це |
|---|---|---|---|---|
| D | 1.900 | **2.000** | 2.100 | розмір корпусу Y |
| E | 1.900 | **2.000** | 2.100 | розмір корпусу X |
| A | 0.900 | — | 1.050 | висота корпусу |
| A3 | 0.650 | — | 0.850 | висота стояння |
| e | **0.500 BSC** | | | крок |
| E1 | **1.580 BSC** | | | розмах рядів площадок X |
| D1 | **1.500 BSC** | | | розмах рядів площадок Y |
| b | 0.270 | **0.325** | 0.380 | довжина площадки |
| b1 | 0.200 | **0.250** | 0.300 | ширина площадки (верх/низ) |
| c | 0.130 | — | 0.300 | ширина площадки (боки) |

## 3. Наш футпринт vs даташит

`arrowstand:LGA-12_L2.0-W2.0-P0.50-TL` (офіційний JLCEDA/EasyEDA):

| Параметр | Даташит | Наш футпринт | Оцінка |
|---|---|---|---|
| Положення площадок | e = 0.500 BSC, E1 = 1.580, D1 = 1.500 | **збігається** | ✓ |
| Ширина (у напрямі кроку) | c = 0.13…0.30 | **0.28** | ✓ у межах |
| Довжина площадки | b = 0.27…0.38 (nom 0.325) | **0.70** | ⚠ вдвічі більша |
| Маркер pin 1 | є (TOP VIEW) | є (CIRCLE) | ✓ |
| Зміщення площадок назовні | b → 0.952 (всередині корпусу) | на ~0.14 мм **за межі корпусу** | ⚠ |

**Висновок: розведення правильне, довжина площадок відрізняється від мінімального
land pattern — і це правильний вибір саме для нашого виробництва:**

1. **JLCPCB розподіляє трафарет саме так.** Його стандарт для мікро-кроку
   0.5 мм (Opening Process Standard): апертура W = 0.24 мм (тобто на 14 %
   менша за наші 0.28 — знизує риск замикання), довжина — «виступає назовні на
   0.1 мм». Отже JLCPCB **очікує** площадки, що виходять за межі корпусу.
2. **IPC-7351B Level A (low density)** — найбільші площадки: JLCPCB приймає
   тільки medium/low density. Наш варіант — саме low density: кращі
   паяні з'єднання, легший ремонт, більший solder-mask dam.
3. **Маска:** зазор між площадками 0.22 мм → dam 0.22 мм — норма для 0.5 мм
   кроку (номінал IPC-7351 для LGA-12: площадка 0.27, зазор 0.23).

**Рішення: футпринт не змінюємо.** Він відповідає офіційній бібліотеці
JLCEDA (з якої ми імпортували) і правилам JLCPCB.

## 4. Параметри з даташиту, важливі для прошивки й алгоритму

| Параметр | Значення | Наслідок |
|---|---|---|
| Діапазони | ±2 / ±4 / ±8 / **±16 g** | 16 g — максимум; понад це — clipping |
| **Ударостійкість** | **10 000 g** | датчик **не зламається** від удару стріли; обрізається лише вимірювання |
| ODR | 1.56 Гц … **4.27 кГц** | наш ACCEL_ODR_HZ_CAPTURE = 3200 Гц — у межах ✓ |
| Розрядність | 12 біт | ±16 g → 78 мг/LSB |
| Інтерфейс | I2C / SPI 4-дротовий / SPI 3-дротовий | 4-дротовий ✓ |
| Вбудовані переривання | 6D/4D-орієнтація, free-fall, одинарний/подвійний клік, motion/wake-up | **апаратна підтримка класифікації** — менше DSP |
| Живлення | 1.71–3.6 В | від 3.3 В ✓ (I/O 1.8 В сумісний) |
| Струм standby | 500 нА | ✓ |
| Самоперевірка | вбудована | можна тестувати датчик без стенда |

**Важливо для алгоритму (ADR-0003, ADR-0008):**
- «Час на рейлі» лишається корисною ознакою, але при 10 000 g ударостійкості
  **сигнал обмежене ±16 g, а не зруйнований** → класифікація на основі
  ознак лишається можливою.
- Вбудовані переривання (клік, 6D, рух) можна використати як **попередню
  фільтрацію** перед власним DSP: MCU прокидається лише коли є кандидат на
  удар, і не на кожен «дзвін» датчика.

## 5. 3D-моделі

Усі 6 деталей з LCSC (arrowstand) не мали 3D-моделей (імпорт із EasyEDA їх не
тягне; `prodlcd.easyeda.com` з цього робочого місця недоступний). Проставлені
**моделі з бібліотеки KiCad** через `set_footprint_models` (жодних зовнішніх
файлів — усе вже є в інсталяції KiCad):

| Футпринт | Модель KiCad |
|---|---|
| `LGA-12_L2.0-W2.0-P0.50-TL` | `Package_LGA.3dshapes/LGA-12_2x2mm_P0.5mm.step` |
| `QFN-24_L4.0-W4.0-P0.50-BL-EP2.6` | `Package_DFN_QFN.3dshapes/QFN-24-1EP_4x4mm_P0.5mm_EP2.6x2.6mm.step` |
| `TQFN-48_L7.0-W7.0-P0.50-BL-EP5.5` | `Package_DFN_QFN.3dshapes/QFN-48-1EP_7x7mm_P0.5mm_EP5.15x5.15mm.step` |
| `SOT-23-5_L3.0-W1.7-P0.95-LS2.8-BL` | `Package_TO_SOT_SMD.3dshapes/SOT-23-5.step` |
| `ESOP-8_L4.9-W3.9-P1.27-LS6.0-BL-EP` | `Package_SO.3dshapes/SOIC-8-1EP_3.9x4.9mm_P1.27mm_EP2.41x3.81mm.step` |
| `CRYSTAL-SMD_4P-L3.2-W2.5-BL` | `Crystal.3dshapes/Crystal_SMD_3225-4Pin_3.2x2.5mm.step` |

Усі інші деталі (R, C, LED, USB-C, SMA, кнопка, тест-точки) — штатні футпринти
KiCad, які **вже** посилаються на свої моделі в `${KICAD10_3DMODEL_DIR}`.

**Відхилення від реального виробника:**
- QFN-48: експонований пад у моделі 5.15×5.15 мм, у EasyEDA — 5.5 мм
  (різниця 0.35 мм по краю — візуально непомітно, на пайку не впливає).
- ESOP-8 (TP4056): KiCad дає SOIC-8-1EP з EP 2.41×3.81 мм; у EasyEDA EP
  ширший (4.9×2.4 мм). Візуальна різниця, не критично.
- Решта — збігається.

## 6. Висновок

Футпринт SC7A20 **перевірено і залишається без змін**. Розведення виводів
1:1 з даташитом, геометрія площадок відповідає офіційній бібліотеці JLCEDA й
правилам трафарету JLCPCB для кроку 0.5 мм. 3D-моделі проставлені для всіх
деталей.
