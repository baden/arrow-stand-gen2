## 3. Обов'язкові вимоги до розводки

### 3.1 RF-траса (критично)

1. **50 Ом мікроstrip** від RFO → L2 → trap (L3 ∥ C18) → C16 → L4 → SMA.
   Ланцюг на 3 деталі довший, ніж «RFO → C16 → SMA»: режектор 2-ї гармоніки
   (обов'язковий для EMC у 863–870 МГц) і фільтр вищих гармонік.
2. **Жодних** розгалужень, перехрестів, змін ширини на трасі. Гілка trap-у
   (L3 ∥ C18) підключається **поперёк** прямої ділянки — вона коротша і
   симетрична відносно прямої траси.
3. Нижня шар — **суцільна GND-площа** під усією RF-трасою, без розривів.
4. **L1 (choke VR_PA) — перпендикулярно** RF-трасі (AN1200.66), щоб не було
   зв'язку. Точка підключення VR_PA — якомога ближче до SX1262.
5. Антенна (SMA, vertical board-mount) — **біля краю плати, з боку мішені**;
   кабель антени виходить **вгору через край** (edge-mount коштує $3.4–15 —
   неприйнятно). Траса 50 Ом підходить до **центрального піна зсередини плати**
   (4 заземлювальні штири навколо нього дають зворотний шлях) — це зручніше за
   edge-mount. Підведення — без металу навколо (мішень — металева!).
6. **Trap (L3 ∥ C18) — на початку RF-траси**, одразу після L2: 2-га гармоніка
   гаситься біля виходу PA, далі вона йде по трасі. DC block C16 — ближче до
   SMA: його власна неідеальність (ESR/ESL) тоді не впливає на trap.

### 3.2 Живлення

1. Силові доріжки: ≥ 0.5 мм, на SX1262 VBAT — до 120 мА.
2. Конденсатори bypass (100 нФ, 10 мкФ) — **≤ 5 мм** від відповідного виводу.
3. Теплові vias під EP QFN-48 (7×7) — сітка 5×5 vias 0.3 мм.
4. Конденсатори VR_PA (100 нФ + 1 мкФ) — ≤ 5 мм від виводу 24.

### 3.3 LGA-12 (SC7A20) — розв'язання

1. **Пружна прокладка 0.3–0.5 мм** під корпусом датчика (ADR-0003, варіант A):
   знижує пік, який бачить датчик.
2. Розміщення датчика — **на боці плати, зверненому до зони улучення**
   (але не на краю — щоб менше було металу поруч).
3. Точки під датчиком — без заливки (щоб не «підпливали»).

### 3.4 DFM JLCPCB

| Правило | Вимога |
|---|---|
| Відстань корпус→край плати | **≥ 2.5 мм** |
| Футпрінти | IPC-7351B medium/low density (наші — low) |
| Мінімальний пакет | 0402 ✓ |
| Мінімальний крок IC | 0.4 мм (у нас 0.5 мм — на межі Economic PCBA) |
| Fiducials | 3 на верхньому шарі (JLCPCB вимагає для PCBA) |
| Tooling holes | за бажанням; JLCPCB додасть сам, якщо немає |
| Розмір PCB | ≥ 10×10 мм (Economic PCBA), ≥ 70×70 мм (Standard) |
| Мінімальний отвір | 0.3 мм ( vias ), діаметр 0.3 мм — за нашою конфігурацією |

> **Увага:** Economic PCBA обмежена 10×10…470×500 мм і мінімум 0402 — ми в межах.
> Але мінімальний крок IC 0.4 мм Economic — наш LGA-12/QFN-48 мають 0.5 мм,
> тобто **Economic PCBA** має шанс. Якщо JLCPCB відхилить — Standard PCBA.

### 3.5 Акумулятор (BT1)

| Параметр | Значення |
|---|---|
| Що містить футпринт BT1 | **тільки 2 отвори під дроти** + обводка 3 × 7 мм навколо них (F.Fab + courtyard) |
| Отвори | 2 × Ø0.7 мм (plated), **pad 1 у (0, +2), pad 2 у (0, −2)** — симетрично в центрі футпринта, відстань 4 мм; позначки «+»/«−» на silk, коло dot pin 1 |
| Розміщення отворів | **довільне** — дроти гнучкі, припаюються там, де зручно |
| 3D-модель у футпринті | під'єднана (offset 0) **для орієнтування**; реальне положення pouch задається вручну (Properties → 3D Models → Edit Model → Offset), бо pouch клеїться окремо від отворів |
| Файл моделі | `hardware/common/packages3d/LiPo_LP802023_240mAh_8x20x23.step` (джерело — `hardware/common/models3d/*.sc`) |

Pouch 20 × 23 мм **не вміщується** на лицьовому боці (плата 30 × 40 мм забита
компонентами) → клеїться на **зворотний** бік, де є вільне місце. Дроти 80 мм
коротшаємо до ~15 мм і припаюємо в отвори BT1.

### 3.6 Силіконі / маркування

- Позначення RefDes на силіконі — обов'язково (збірка й ремонт).
- Позначення радіочастотної зони, USB, LED-каналів хаба.
- Розмітка «+» біля TP5 (BAT+) і TP6 (BAT−) та «CHG» біля входу зарядки.

## 4. Що далі (за порядком)

1. Розкласти футпрінти (мішень: SX1262 → SMA в один бік, L1 перпендикулярно
   RF-трасі, Y1 поруч із SX1262; хаб: 10 LED у ряд, MCU в центрі).
2. Контур плат під реальні розміри.
3. Живлення: ширина доріжок, bypass-конденсатори, теплові vias.
4. RF-траса 50 Ом.
5. DRC (KiCad) + JLCDFM.
6. Експорт Gerber + BOM для замовлення.
