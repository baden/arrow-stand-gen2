## 3. Що саме узгоджено в референсі (AN1200.40 §3, §4)

### 3.1 TX-ланцюг (з рисунка Figure 1/5 — SX1261/1262 + PE4259)

```
VR_PA(24) ──L1── RFO(23) ──L2── L3 ──L4── [PE4259 RF1]
                            │    │    │
                            C3  C5   C7
                            │    │    │
                           GND  C6(L4)  GND
                                 │
        L3 ∥ C4  ← режектор 2-ї гармоніки
```
| Стадія | Елементи | Що робить |
|---|---|---|
| Узгодження | **L2, L3 + C3, C5** | перетворити Zopt PA на 50 Ом |
| **Режектор 2-ї гармоніки** | **L3 ∥ C4** | L новий = ¾ L3; C4 резонує на 2·f0 |
| Фільтр вищих гармонік (π, 50→50) | **C5, L4, C6, C7** | 3-га й вище гармоніки |
| DC block | **C6** | «захищає вхід RF-перемикача» |
| Узгодження з антеною | **C8, C9, L5, C10** | підгонка під конкретну антену (50 Ом) |

### 3.2 RX-фронтенд (балун)

`RFI_P/RFI_N` — **диференційні** входи LNA (SX1261/2 DS Rev 1.2: «The received
RF signal is first amplified by a **differential** Low Noise Amplifier»).

Топологія з SX1261/2 DS Rev 1.2 §14.5 (типове застосування) — Figure 15
AN1200.40:

```
ANT ── C13 ── GND          (шунт антенного вузла)
ANT ── C11 ── ● ────────── RFI_N
                  │
                 L6
                  │
                  ● ────────── RFI_P
                  │
                 C12 ── GND   (шунт вузла RFI_P)
```

- **C11** — послідовний DC block: антенний вузол → RFI_N.
- **L6** — послідовний елемент між RFI_N і RFI_P (диференційний ланцюг).
- **C12** — шунт у вузлі RFI_P; **C13** — шунт антенного вузла
  (у AN1200.40 — «optional, додаткове придушення завад»).

Оптимальний диференційний опір джерела: **74 + j134 Ом** (source-pull
SX1261, 915 МГц).

> **Наслідок для нашого хаба (2026-11-19):** якщо обидва входи LNA живились
> б від **однієї** антенної точки (як було в нашій схемі до виправлення),
> вони отримували б той самий сигнал **у фазі** → диференційний сигнал ≈ 0.
> Тобто «втрата чутливості 3–6 дБ» — це недооцінка: хаб фактично не приймав.

### 3.3 Методика (AN1200.40 §3.1)

1. **Load-pull** на виводі RFO → Zopt: для SX1261 на 915 МГц — **11.7 + j4.8 Ом**
   (макс. потужність) або 13.5 + j7.6 Ом (вища ККД).
2. **Симуляція** мережі в ADS/Ansoft → номінали.
3. **Фізична підгонка** на VNA (завжди потрібна: паразити PCB, номінали).
4. Після додавання RF-перемикача — повторні вимірювання.

> **Висновок: номінали в референсі — результат load-pull + симуляції + підгонки.
> Тобто «узгоджено» там не означає «перенесіть номінали на іншу частоту» —
> треба зробити те саме для 433 МГц.

## 4. Чого бракує в нашій схемі

### 4.1 Мішень (TX-only) — критична прогалина: фільтр 2-ї гармоніки

Стан **до 2026-11-19** (`docs/architecture/schematic-spec.md` §3):

```
VR_PA(24) ──L1 56 нГ── RFO(23) ──C16 (DC block)── ANT_RF ──C16?? ── J1 (SMA)
```

| Стадія з референсу | Було | Стан |
|---|---|---|
| Узгодження Zopt → 50 Ом | L1 + C16 + C12 | **узгодження фактично відсутнє** — значення TBD, а Zopt для 433 МГц невідомий |
| **Режектор 2-ї гармоніки** | — | **НЕМАЄ** ❌ |
| Фільтр вищих гармонік (π) | — | **НЕМАЄ** ❌ |
| Узгодження з антеною | C12 (шунт) | частково |

**Статус після 2026-11-19:** усі чотири стадії реалізовано (ADR-0009):
L2+C17 (узгодження), **L3 ∥ C18** (trap 866.1 МГц), C19+L4+C12 (фільтр вищих
гармонік), C16 (DC block). Значення — розрахункові стартові, підтвердження на
стенді (R-15).

**Чому режектор 2-ї гармоніки обов'язковий саме для 433 МГц:**

- 2-га гармоніка несучої = **433.05 × 2 = 866.1 МГц** — це **точно ISM-смуга
  863–870 МГц**, де живуть LoRaWAN та інші ISM-пристрої (в т.ч. в Україні).
- Типовий PA SX1262 дає 2-гу гармоніку на рівні ≈ −25…−30 dBc від основної.
  При TX +14 dBm (25 мВт) це **≈ −11…−16 dBm** у смузі 863–870 МГц.
- Ліміт небажаних випромінювань EN 300 220 у цій смузі — порядку **−36 dBm** ⇒
  потрібне **придушення ≥ 20–25 dB** на 866 МГц.
- У референсі це робить **паралельний LC (L3 ∥ C4)**, настроєний на резонанс
  2-ї гармоніки (глибокий нуль).

> **Висновок: без режектора наш пристрій не має права випромінювати в
> 863–870 МГц.** Це не «покращення дальності», а **вимога електромагнітної
> сумісності** (і «добросусідства» до LoRaWAN-сусідів). Разом із TX +14 дБм
> (замість +22) ми вже зробили найбільшу частину роботи, але нуль на 866 МГц
> лишається.

### 4.2 Хаб (RX-only) — багував RX-фронтенд (виправлено 2026-11-19)

**Як було** (до 2026-11-19): обидва входи диференційного LNA живились від
**однієї** точки `ANT_RF` через окремі DC block-и.

| Елемент | Що треба (за DS) | Було | Статус |
|---|---|---|---|
| C11 | DC block антенний вузол → RFI_N | C14 (RFO… ANT_RF → RFI_P) | не відповідало |
| L6 | диференційний ланцюг RFI_N ↔ RFI_P | **не було** | **БУГ** ❌ |
| C12 | шунт у вузлі RFI_P | C15 (ANT_RF → RFI_N) | не відповідало |
| C13 | шунт антенного вузла | C16 (шунт ANT_RF) | ✓ |
| C13 (TX DC block, DNP) | TX-ланцюг хаба від'єднано | ✓ | правильно |

**Чому це баг, а не «втрата 3–6 дБ»:** LNA — диференційний. Живлення обох
виводів від однієї точки означає, що на RFI_P і RFI_N приходить той самий
сигнал **у фазі** → різниця ≈ 0 → хаб фактично не приймав (лишився б тільки
асиметрія номіналів).

**Виправлено** (ADR-0009): C14 = DC block `ANT_RF` → RFI_P, **L2** = балун
RFI_P ↔ RFI_N, C15 = шунт RFI_N → GND, C16 = шунт `ANT_RF` → GND.

**Добре:** TX-вихід PA у хабі від'єднано (C13 DNP) — інакше вихід PA навантажував
би вхід LNA.

## 5. Що робимо

### 5.1 Мішень: мінімальний TX-ланцюг (без RF-перемикача) — реалізовано

Оскільки мішень **тільки передавач**, референсну схему сильно спрощуємо:

```
RFO(23) ──[L2]──┬──[L3 ∥ C18]──┬──[C16]──[L4]── J1 (SMA)
                │                │         │
            [C17]               │      [C19]
                │                │         │
               GND              └─────────┘
```

| Елемент | Призначення | Номінал (розрахунково, R-15) |
|---|---|---|
| L1 56 нГ | choke VR_PA (вже є) | 56 нГ, >130 мА |
| L2 + C17 | узгодження Zopt → 50 Ом | 3.3 нГ + 3.3 пФ |
| **L3 ∥ C18** | **режектор 2-ї гармоніки на 866.1 МГц** | 3.3 нГ + 10 пФ = 876 МГц |
| C19 + L4 + C12 | фільтр вищих гармонік (π 50→50) | 3.3 пФ + 3.3 нГ + 10 пФ |
| C16 | DC block | 100 пФ |

Реалізація в схемі мішені: `L2`, `L3`, `L4`, `C12`, `C16`, `C17`, `C18`, `C19`
(ERC 0/0, orphans 0, shorts 0; нетліст KiCAD підтверджує trap L3 ∥ C18).

Режектор за AN1200.40 §3.1.3: «The new inductor value is chosen to be 3/4 of the
original L3, and C4 is calculated to resonate out the second harmonic» — ми
використали L3 = 3.3 нГ як окремий trap-індуктор, тому правило ¾ стосується
**окремого** індуктора узгодження (у нас ним є L2).

### 5.2 Хаб: RX-балун — реалізовано

```
ANT_RF ──┬──[C16 10 пФ]── GND
         │
        [C14 100 пФ]
         │
    RFI_P ●──[L2 10 нГ]──● RFI_N
                          │
                     [C15 10 пФ]
                          │
                         GND
```
(C11 + L6 + C12 + C13 з референсу; значення розрахункові, R-15.)

### 5.3 Кроки

| # | Крок | Результат |
|---|---|---|
| **R-17** | запит у Semtech: load-pull Zopt та номінали TX/RX мереж **для 433 МГц**; можливо — файли референсного PCB | готова топологія з номіналами |
| **R-15** | налаштування на стенді (NanoVNA): S11 на SMA + придушення на 866 МГц | фінальні номінали в BOM |
| **R-18** | вимірювання гармонік TX (спектроаналізатор або NanoVNA на 2-му гармоніку) | підтвердження ≤ −36 dBm у 863–870 |
| — | перенести узгоджену мережу в обидві схеми (BOM-спільні позиції) | мішень + хаб |
