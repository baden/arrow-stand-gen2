## 3. Що саме узгоджено в референсі (AN1200.40 §3, §4)

### 3.1 TX-ланцюг (з рисунка Figure 1/5 — SX1261/1262 + PE4259)

```
VR_PA(24) ──L1── RFO(23) ──L2── L3 ──L4── [PE4259 RF1]
                            │    │    │
                            C3  C5   C7
                            │    │    │
                           GND  C6(L4)  GND
                                 │
        L3 ∥ C4  ← режектор 2-ї гармоніки
```
| Стадія | Елементи | Що робить |
|---|---|---|
| Узгодження | **L2, L3 + C3, C5** | перетворити Zopt PA на 50 Ом |
| **Режектор 2-ї гармоніки** | **L3 ∥ C4** | L новий = ¾ L3; C4 резонує на 2·f0 |
| Фільтр вищих гармонік (π, 50→50) | **C5, L4, C6, C7** | 3-га й вище гармоніки |
| DC block | **C6** | «захищає вхід RF-перемикача» |
| Узгодження з антеною | **C8, C9, L5, C10** | підгонка під конкретну антену (50 Ом) |

### 3.2 RX-фронтенд (балун)

`RFI_P/RFI_N` — **диференційні** входи LNA. Мережа **C11 + L6** (послідовна +
шунт) виконує **балун** (single-ended → differential) **і** трансформацію
імпедансу; **C12, C13** — шунти (C13 = «optional, додаткове придушення
завад»). Оптимальний диференційний опір джерела: **74 + j134 Ом** (source-pull
SX1261, 915 МГц).

### 3.3 Методика (AN1200.40 §3.1)

1. **Load-pull** на виводі RFO → Zopt: для SX1261 на 915 МГц — **11.7 + j4.8 Ом**
   (макс. потужність) або 13.5 + j7.6 Ом (вища ККД).
2. **Симуляція** мережі в ADS/Ansoft → номінали.
3. **Фізична підгонка** на VNA (завжди потрібна: паразити PCB, номінали).
4. Після додавання RF-перемикача — повторні вимірювання.

> **Висновок: номінали в референсі — результат load-pull + симуляції + підгонки.
> Тобто «узгоджено» там не означає «перенесіть номінали на іншу частоту» —
> треба зробити те саме для 433 МГц.

## 4. Чого бракує в нашій схемі

### 4.1 Мішень (TX-only) — критична прогалина: фільтр 2-ї гармоніки

Наша ланцюг зараз (`docs/architecture/schematic-spec.md` §3):

```
VR_PA(24) ──L1 56 нГ── RFO(23) ──C16 (DC block)── ANT_RF ──C16?? ── J1 (SMA)
```

| Стадія з референсу | У нас | Стан |
|---|---|---|
| Узгодження Zopt → 50 Ом | L1 + C16 + C12 | **узгодження фактично відсутнє** — C12/C16 мають значення TBD, а Zopt для 433 МГц невідомий |
| **Режектор 2-ї гармоніки** | — | **НЕМАЄ** ❌ |
| Фільтр вищих гармонік (π) | — | **НЕМАЄ** ❌ |
| Узгодження з антеною | C12 (шунт) | частково |

**Чому режектор 2-ї гармоніки обов'язковий саме для 433 МГц:**

- 2-га гармоніка несучої = **433.05 × 2 = 866.1 МГц** — це **точно ISM-смуга
  863–870 МГц**, де живуть LoRaWAN та інші ISM-пристрої (в т.ч. в Україні).
- Типовий PA SX1262 дає 2-гу гармоніку на рівні ≈ −25…−30 dBc від основної.
  При TX +14 dBm (25 мВт) це **≈ −11…−16 dBm** у смузі 863–870 МГц.
- Ліміт небажаних випромінювань EN 300 220 у цій смузі — порядку **−36 dBm** ⇒
  потрібне **придушення ≥ 20–25 dB** на 866 МГц.
- У референсі це робить **паралельний LC (L3 ∥ C4)**, настроєний на резонанс
  2-ї гармоніки (глибокий нуль).

> **Висновок: без режектора наш пристрій не має права випромінювати в
> 863–870 МГц.** Це не «покращення дальності», а **вимога електромагнітної
> сумісності** (і «добросусідства» до LoRaWAN-сусідів). Разом із TX +14 дБм
> (замість +22) ми вже зробили найбільшу частину роботи, але нуль на 866 МГц
> лишається.

### 4.2 Хаб (RX-only) — немає балуна

Хаб приймає, але без балуна:

| Елемент | Що треба | Стан |
|---|---|---|
| C11, L6 | **балун**: single-ended → differential + трансформація 50 Ом → 74 + j134 Ом | **НЕМАЄ** ❌ |
| C12, C13 | шунти на входах LNA (C13 — додаткове придушення завад) | **НЕМАЄ** ❌ |
| C14, C15 | у нас: DC block до RFI_P/RFI_N | схема «роботає», але без трансформації → втрата чутливості (орієнтовно 3–6 дБ) |
| C16 | у нас: шунт на ANT_RF | не відповідає референсу (має бути в балуні) |
| C13 (TX DC block, DNP) | TX-ланцюг хаба від'єднано ✓ | правильно |

**Добре:** в хабі TX-вихід PA від'єднано (C13 DNP) — інакше вихід PA навантажував
би вхід LNA.

**Погано:** RX-фронтенд хаба — це не референсна схема, а « capacitive feed ».
Для чутливості потрібен балун (3 елементи) + узгодження.

## 5. Що робимо

### 5.1 Мішень: мінімальний TX-ланцюг (без RF-перемикача)

Оскільки мішень **тільки передавач**, референсну схему сильно спрощуємо:

```
RFO(23) ──[L_match]──┬──[C_notch]──┬──[L_f1]──[C_dc]──[L_f2]── J1 (SMA)
                      │             │                         │
                   (C_match)    (L_n ∥ C_n @866 МГц)          C_out
```

| Елемент | Призначення | Номінал |
|---|---|---|
| L1 56 нГ | choke VR_PA (вже є) | 56 нГ, >130 мА |
| L_match + C_match | узгодження Zopt → 50 Ом | TBD (R-15) |
| **L_n ∥ C_n** | **режектор 2-ї гармоніки на 866 МГц** | TBD (R-15) |
| L_f1, C_dc, L_f2, C_out | фільтр вищих гармонік + DC block + узгодження з антеною | TBD (R-15) |

Номінал режектора орієнтовно: резонанс 866 МГц → наприклад L_n = 12 нГ,
C_n = 2.8 пФ (LC-резонанс) — **але підбирається разом із рештою мережі**
(AN1200.40 §3.1.3: «The new inductor value is chosen to be 3/4 of the original
L3, and C4 is calculated to resonate out the second harmonic»).

### 5.2 Хаб: додати балун RX

```
ANT_RF ──[C_b1]──┬── RFI_P
                  └──[L_b]── GND
ANT_RF ──[C_b2]──┴── RFI_N
                     (C_sh1, C_sh2 — шунти на входах)
```
(C11 + L6 + C12 + C13 з референсу; значення — TBD, R-15.)

## 6. Вартість наслідків

| Стаття | Δ | Коментар |
|---|---|---|
| 4–5 нових RF-деталей у мішені (2 L + 3 C, 0402) | **+$0.02…0.05** | базові LC-компоненти |
| 3 деталі балуна в хабі | +$0.01…0.02 | |
| Зміна плану розводки (RF-ланцюг довший) | +2…4 мм довжини | 50 Ом мікроstrip, без розгалужень |
| **Разом** | **≈ +$0.05** | пристрій $4.036 → **$4.09** (в межах цілі $4.10) |

Але головне — **це не витрата, а відсутність блокера**: без придушення
2-ї гармоніки пристрій не відповідає вимогам EMC/спектральної чистоти в
863–870 МГц, і в разі з іншими ISM-пристроями (LoRaWAN) ми будемо заважати
сусідам.
