# Двосторонній зв'язок: референсна схема з RF-комутатором — розрахунок різниці

> **Статус:** розрахунок (рішення не прийняте) · 2026-11-19 · запит власника
> **Джерела:** AN1200.40 Rev 1.1 (Figure 15, §3.1.3), SX1261/2 DS Rev 1.2
> (§14.5 Application Schematics, Table 3-5, DIO2), PE4259 DS DOC-03694-5.01,
> LCSC (ціни зі сходинки @100 шт)
> **Пов'язані:** ADR-0001 (радіо), ADR-0007 (протокол), ADR-0009 (RF-мережа),
> `docs/manufacturing/power-budget.md`, `docs/cost/budget.md`

## 1. Відповідь одним абзацом

**Гроші — не перешкода:** референсна двостороння схема коштує **+$0.143/шт
на мішені** (3.5 % пристрою) і **+$0.150/шт на хабі**, плюс **+$3** setup-fee
за один новий Extended-артикул (комутатор). Ваша теза «якщо питання тільки в
парі компонентів» — **підтверджується**.

**Але є три витрати, які гроші не покривають:**

| # | Витрата | Величина | Наслідок |
|---|---|---|---|
| 1 | **Втрати в комутаторі** (IL) | −0.35 дБ на кожному кінці | −4 % дальності на один кінець, **−8 %** якщо комутатор на обох |
| 2 | **Струм комутатора в standby** | +9 мкА typ / +20 мкА max | idle мішені 32 → 41…52 мкА → **час життя 233 → 182…143 діб** (−22…−39 %) |
| 3 | **Протокол і прошивка** | ADR-0007 → двобічний, RX у мішені, UI налаштувань, **автентифікація команд** | це 90 % роботи, не метал |

Плюс: комутатор **не можна додати пізніше без респайну PCB** (SMA на краю,
RF-траса не перекладається) — але плата мішені ще й так перемальовується.

## 2. Що таке референсна двостороння схема

### 2.1 Топологія (AN1200.40 Figure 15 + SX1261/2 DS §14.5)

```
                                        ┌──── PE4259 (SPDT) ────┐
TX: RFO → [match] → [trap 2f0] → [π] → C_dc ──► RF2      RFC ──► [антенне узгодження] ──► SMA
RX: RFI_P ─┐                                              RF1 ◄── [C11 + L6 + C12] ◄──┘
           └────────────────────────────────────────────────────────────────────────────────┘
Керування: SX1262 DIO2 → R 100 Ом → CTRL комутатора        (C 1 нФ з CTRL на GND)
Живлення комутатора: VDD (вивід 6) ← 3.3 В + bypass 100 нФ
```

**Антенне узгодження (C8/C9/L5/C10 у референсі) не потрібне** — наша
антенна AILF002 з кабелем і SMA-штекером на 50 Ом.

### 2.2 Комутатор PE4259 (і клони)

| Параметр | Значення | Джерело |
|---|---|---|
| Втрати в комутаторі (IL) | **0.35 дБ typ** @1 ГГц (0.45 min / 0.60 max); на 433 МГц ~0.3 дБ | PE4259 DS Table 3 |
| Ізоляція портів | 29 дБ min @1 ГГц | Table 3 |
| Зворотне відбиття | 21 дБ typ @1 ГГц | Table 3 |
| Час перемикання | 1.5 мкс | Table 3 |
| **Струм живлення VDD** | **9 мкА typ / 20 мкА max** (VDD = 3 В, CTRL = 3 В) | DS Table 2 |
| Живлення / CTRL | VDD 1.8…3.3 В; CTRL — одиничний CMOS-вхід (High → RFC↔RF1, Low → RFC↔RF2) | DS Table 2, Table 5 |
| **Tuning-конденсатор** | **обов'язковий на платі** (зауваження 2 до Table 3, Figure 13) | PE4259 DS |
| Корпус | SOT-363 (SC-70-6) | LCSC |

### 2.3 Керування — окрема деталь на користь цього варіанта

SX1262 має **вбудовану команду `SetDio2AsRfSwitchCtrl(...)`**: у цьому режимі
**DIO2 = 1 під час TX і 0 в усіх інших режимах** (DS Rev 1.2, розділ про
DIO2). Тобто:

- не треба окремого GPIO і не треба керувати комутатором у прошивці вручну —
  одна команда при ініціалізації;
- DIO2 = 0 у сні → комутатор у позиції RX → PA вимкнений, витоку немає;
- **жодних додаткових вивідних ліній SX1262 не потрібно** (DIO2 зараз NC).

## 6. Живлення — головна прихована витрата

### 6.1 Standby-комутатора

| | Струм | Час життя (idle) | +10 влучань/добу |
|---|---|---|---|
| Зараз | 32 мкА | 233 діб | 183 діб |
| + комутатор (typ) | 41 мкА | 182 діб | 143 діб |
| + комутатор (max) | 52 мкА | 143 діб | 112 діб |

**Комутатор не має режиму power-down** (VDD вимкнено → стан портів
невизначений, DS не гарантує ізоляцію) → ці 9…20 мкА платимо **завжди**,
навіть якщо двосторонній зв'язок так і не використовуватиметься.

### 6.2 Якщо двосторонній зв'язок реально використовувати

Щоб мішень «слухала» команди, вона має періодично прокидатися в RX.
SX1262 у RX (LDO-режим, LoRa 125 кГц) = **8 мА** (DS Table 3-5).

| Вікно прослуховування | Середній струм | Idle разом |
|---|---|---|
| 50 мс кожні 60 с | +6.7 мкА | 48 мкА → 155 діб |
| 100 мс кожні 60 с | +13.4 мкА | 54 мкА → 138 діб |
| без прослуховування (лише «сліпий» TX) | +0 | 41 мкА → 182 діб |

> Тобто **реальна** двосторонність (−22…−39 % часу життя) — це не комутатор,
> а **вікно прослуховування**. Комутатор — це плата за саму можливість.

## 7. Площа на платі

| | Площа |
|---|---|
| Комутатор SOT-363 (land pattern) | ~15 мм² |
| 6 × 0402 (CTRL R/C, bypass, tuning, RX-балун) | ~6 мм² |
| **Разом** | **~21 мм²** |

Плата мішені за планом — 45 × 50 мм (2250 мм²), зайнято ≈ 660 мм² →
**місця вистачає з великим запасом**. Хаб (50 × 85 мм) — тем паще.

> **Сторожка:** контур у файлі плати застарілий — `gr_rect` 20 × 40 мм
> (125…145 / 75…115), тоді як 9 деталей лежать **поза ним**, а план
> (`pcb-layout-plan.md` §1) каже 45 × 50 мм. Тобто плату перемальовувати
> однаково — **додаткової роботи з компонування комутатор не створює**.

## 10. Висновок і точка рішення

1. **Грошова перешкода відсутня** (+3.5 % пристрою, +$3 setup) — ваша теза
   підтверджена.
2. **Але комутатор має ціну, яку не видно в BOM:** −0.35 дБ (неперевірений
   запас дальності) і **+22…−39 % часу життя** — навіть без
   використання двостороннього зв'язку.
3. **Справжня вартість двостороннього зв'язку — не металеві, а протокол і
   безпека** (розділ 8).
4. **Таймінг:** плата мішені ще перемальовується (контур застарілий) →
   додати комутатор зараз **не коштує додаткової роботи з компонування**.
   Відкласти = респайн ($0.45–0.60/шт + складання + час).
5. **Рекомендація:** три шляхи, і я б обрав між ними так:
   - якщо сценарій «дистанційне налаштування» **не підтверджено як реальна
     потреба** → **лишити односторонню**; комутатор не дає «опції без
     плати», він дає опцію **зі втратою дальності й часу життя**;
   - якщо потреба **підтверджена** → **варіант B (повний референс)**;
     при цьому варто закласти в прошивку й `DIO2` як `SetDio2AsRfSwitchCtrl`
     (одна команда) і одразу передбачити вікно прослуховування в
     power-budget;
   - якщо двосторонність потрібна, але **не хочеться втрачати дальність і
     час життя** → **варіант C (два антенні порти)** замість комутатора:
     на $0.17 більше, але 0 дБ втрат і 0 мкА.
